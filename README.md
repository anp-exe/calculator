# Simple Calculator 🧮

A basic command-line calculator written in C++.

It asks for two numbers and an operator (`+`, `-`, `*`, `/`), then prints the result. Includes a divide-by-zero check so it doesn't crash.

## About

This project is part of the **Codédex C++ course**, built while learning the fundamentals of C++.

## What I learned

- The difference between `cout` (output) and `cin` (input)
- Declaring variables with types like `double` and `char`
- Why `char` uses single quotes (`'+'`) and not double quotes (`"+"`)
- Using `if` / `else if` to branch logic
- Comparing values with `==` instead of assigning with `=`

## How to run

Compile and run with any C++ compiler:

```bash
g++ calculator.cpp -o calculator
./calculator
```

Or just build and run it through CLion.
